# 《换面》人工试玩与公平性检查

本清单用于发布前人工检查和后续盲测。**当前尚未完成真人盲测；清单项没有默认通过。** 自动验算通过只说明配置和公开信息推理满足相应检查，不代表玩家已经理解规则或体验时长已经得到验证。

## 记录方式

- 每次记录日期、浏览器与版本、屏幕尺寸、是否首次游玩、扫雷经验、所测关卡 ID。
- 每项填写：通过 / 未通过 / 未覆盖，并记录可复现操作、实际表现和预期表现。
- 首轮建议 8—12 名玩家，兼顾扫雷新手与熟手。该人数是计划目标，尚非已完成样本。
- 先让玩家独立尝试，再问其如何理解。观察者不要解释谜题答案；需要帮助时记录玩家使用了哪级提示。
- 在玩家许可后记录停滞、误判和口述内容；无需采集姓名、邮箱等个人资料。

## A. 首次进入与操作

- [ ] 从部署后的 `/Minesweeper/huanmian/` 进入，标题、章节、棋盘、规则卡完整显示；没有空白区域或缺失资源。
- [ ] 首关直接可玩。玩家可以用自己的话解释“打开所有安全格即可完成，标记只是笔记”。
- [ ] 左键打开、右键笔记、方向键移动、Enter 打开、F 标记均与帮助文案一致。右键不会触发打开。
- [ ] 工具栏当前状态清楚；选中“标雷 / 标安全”后点击格子只产生笔记，能再次点击取消。
- [ ] 点击已确认安全或已确认雷不会再记一次误判，不会改变已知事实。
- [ ] 故意误开一个雷：只确认该雷并增加一次误判，其他未知格保持未知，仍可继续完成。
- [ ] 标错一格后撤销，只还原笔记；已打开格、误判和采样证据不会被撤销。
- [ ] 重开本关明确清空本关状态；雷位和初始条件保持该关的固定配置。
- [ ] 完成弹窗可以关闭、进入下一关或回到地图。最后一关没有越界、死循环或失效按钮。

## B. 数字、负形与综合

- [ ] 数字章可以解释邻接范围：内部、边缘、角落的邻格总数不同；自身不算邻格。
- [ ] 选中边缘与角落，轮廓高亮与规则卡的“有效邻格”一致。
- [ ] 负形章玩家能复述“数字统计安全邻格，包含已经打开的安全格”。
- [ ] 若在综合关切换“邻雷数 / 安全数”，两种显示之和等于该格实际邻格总数；切换不增减证据或更换雷位。
- [ ] 负形中“大数 = 安全多”被正确理解。若遇到安全数 0，玩家不会被旧规则诱导成零雷自动展开。
- [ ] 安全数等于邻格总数时，自动展开依据真实邻域事实；错误笔记不会触发展开或阻止确定展开。
- [ ] 默认安全笔记与“已确认安全”的表现能区分。玩家不会把勾当作系统已经验证的答案。
- [ ] 综合关需要实际迁移理解；如果玩家只是重复熟记位置或跟随高亮，记录这一问题。

## C. 图形约束

- [ ] 不看答案，仅凭规则卡能说出模板形状、数量、允许旋转、不跨边界、不重叠。
- [ ] 每个模板的示意清楚；模板不能被理解为“看到类似轮廓就必须是雷”。
- [ ] 候选图库被理解为“符合公开证据的可能雷位”，不被误认为答案列表或隐藏真值。
- [ ] 公开新线索后候选减少；放置或撤销个人笔记不排除候选。
- [ ] 玩家能指出一个局部数字不足、图形约束参与排除的步骤；记录其理由与卡住的位置。
- [ ] 不依赖颜色、中文文字联想、图片相似或观察者解释，仍可完成图形判断。
- [ ] 本版若没有拖动图形叠影，文案和试玩说明不会让玩家寻找不存在的拖动操作。

## D. 概率、候选与采样

- [ ] 玩家能区分未知格上的“本格有雷概率”和已开格上的“未知邻域平均雷密度”。
- [ ] 已开安全格显示非零百分比时，玩家不误认为该格仍有雷；选中说明明确分母与含义。
- [ ] 同一公开证据下，任意放旗、标安全、撤销笔记、切换候选图库都不改变概率和候选数。
- [ ] 无伤采样选择的区域在点击前可识别；返回该区域真实雷数，结果被保留，已采区域不能重复收费或重复计数。
- [ ] 新证据只减少或保持候选。无法排除全部合法候选，不出现 NaN、除零、负概率或超过 100%。
- [ ] 初始 50% 的格子不会随等待或重新渲染改变；“雷位固定，更新的是证据”可被玩家复述。
- [ ] 0% 只有精确确定时才算安全。批量整理只打开公开证据确定安全的格子。
- [ ] 已确认邻域为空时显示“邻域已确认”，不把无分母情况显示成误导的 0%。
- [ ] 第三次及后续采样仍可继续，记录辅助完成；两次只作为优秀目标。
- [ ] 刷新后采样结果、候选和计数相同；撤销笔记也不会删除采样证据。
- [ ] 玩家至少作出一次“选哪个区域能区别候选”的决策。如果只追随 0% 点击就能完成整章，记录为玩法价值风险。

## E. 向量实验扩展

- [ ] 玩家知道雷群固定为不重叠 2×2 方块，箭头指最近中心，不直接判断箭头穿过格子的真假。
- [ ] 规则卡明确欧氏距离、八方向和方向边界；距离相同时显示全部并列方向。
- [ ] 同方向多个并列中心的数量能被辨认；缩小屏幕或放大页面后也不相互遮挡。
- [ ] 至少观察一次“箭头穿过安全格”的反例，玩家能够说明为何仍然合理。
- [ ] 数字锚点与箭头同时出现时，能辨别哪部分是邻雷数，哪部分是方向。
- [ ] 若失败主要来自读箭头、角度或术语而不是推理，记录为暂缓扩展的依据。

## F. 空间实验扩展

- [ ] 规则卡明确这是精选程序节点，而不是用户扫描素材或完整点云重建。
- [ ] 点击或键盘选中一个节点，固定半径内的真实邻居高亮；自身不被算入。
- [ ] 旋转、复位、分层显示前后，选中节点 ID、邻接、高亮数量、已公开数字与证据均保持一致。
- [ ] 投影中看起来接近的节点未必相邻；玩家能通过高亮理解深度关系。
- [ ] 所有节点在至少一种可用视角下可点击，没有永久遮挡、重复点击到另一个点或失去焦点。
- [ ] 前后层不单靠颜色区分；分层操作和节点标签能够辅助定位。
- [ ] 若误点、遮挡或空间定位占据大多数失败原因，先修交互，不用增加谜题难度掩盖问题。

## G. 存档、界面与可访问性

- [ ] 中途刷新，恢复当前关、公开事实、笔记、提示次数、采样次数、误判和完成记录。
- [ ] 关卡地图切换后再返回，原关进度保留；实验扩展与 18 关二维主线的范围清楚。
- [ ] 浏览器无法写本地存储时，仍可游玩并明确说明本次不能保存，不静默声称已保存。
- [ ] 键盘可以进入棋盘、工具栏和对话框。对话框打开后焦点在其中，Esc 可关闭，关闭后能继续操作。
- [ ] 100% 和 200% 页面缩放时，关键按钮和文案不重叠。桌面常见屏幕下无需横向滚动才能操作棋盘。
- [ ] 降低动态效果系统设置得到尊重；提示不依赖动画才能被发现。
- [ ] 关闭音效后无提示音；音效默认关闭，开启动作由玩家主动操作。
- [ ] 文字、数字、图标共同表达状态，关闭颜色辨识或使用灰阶仍能区分关键含义。
- [ ] 手机尺寸只作为补充检查；本版优先桌面体验，不据此宣称完整触屏适配已经通过。
